Integrasi Google Sheets & Google Apps Script

Hubungkan Google Sheets agar data transaksi, dataset, dan pesan harian tersimpan rapi dalam baris & kolom spreadsheet online Anda.

📋 Cara Pemasangan Mudah:

  1. Buka Google Sheets Baru.
  2. Klik menu: Ekstensi → Apps Script.
  3. Salin kode dari file google-script.gs di repo ini, lalu paste.
  4. Klik Deploy → New Deployment → Pilih Web App → Akses: Anyone.
  5. Copy URL yang dihasilkan dan tempelkan pada kolom di atas!

Pengaturan API Key Dinamis (Groq / Gemini)

Masukkan API key Groq atau Google Gemini Anda di sini.

Panduan Deploy 24/7 Gratis Ke Render.com

Ikuti 4 langkah sederhana berikut agar bot WhatsApp Anda online 24 jam nonstop gratis tanpa server VPS sendiri!

Langkah 1: Hubungkan ke GitHub

Unggah seluruh file repository ini ke akun GitHub pribadi Anda.

Langkah 2: Buat Web Service di Render

Buka dashboard.render.com → Klik New + → Pilih Web Service → Hubungkan repository GitHub Anda.

Langkah 3: Setting Command Render

  • Runtime: Node
  • Build Command: npm install
  • Start Command: npm run start

Langkah 4: Tautkan WhatsApp

Setelah Render selesai membangun aplikasi, buka URL Render Anda dan masukkan Kode Pairing OTP untuk menghubungkan bot WhatsApp Anda secara online!
